# Волшебный мир (Magic World) 🌰

> Шифр проекта: **ACORN**

Детская приключенческая 2.5D-игра, которую делают папа и двое детей.

Эльф или волшебник исследует волшебный лес, убирает мусор, собирает магические кристаллы и превращается в зверят. Боссов побеждают не силой, а **починкой**: отремонтированные предметы дают боссу отпор, а побеждённого босса расколдовывают.

## Как запустить

1. Установите **Godot 4.7.2** (стандартная версия, не .NET) с [godotengine.org](https://godotengine.org/download). На всех компьютерах должна быть одна и та же версия.
2. Установите [Git LFS](https://git-lfs.com) и выполните `git lfs install`.
3. Склонируйте репозиторий:
   ```bash
   git clone git@github.com:vidiaievd/acorn.git
   ```
4. В Godot: **Import** → выберите `project.godot` → **Run** (F5).

## Структура

| Папка | Что внутри |
|---|---|
| `art_source/` | Исходники рисунков Krita (`.kra`, хранятся в LFS) |
| `assets/` | Готовые PNG, звуки, музыка |
| `scenes/` | Сцены игры: герои, зверьки, кристаллы, боссы, мир |
| `scripts/` | Общие скрипты (autoload) |
| `addons/` | Плагины Godot |
| `docs/` | Документы проекта |

## Коммиты

Начинайте сообщение коммита с ID шага из плана, например: `S4.2: монета при уборке мусора`.
