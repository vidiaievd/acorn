# План имплементации: Волшебный мир (ACORN)

Подробная разбивка спринтов из [GAME_DESIGN.md](GAME_DESIGN.md) на маленькие шаги. Один шаг — это одна логическая задача: один стикер на доске и обычно один коммит.

## Как читать таблицы

**ID:** `S<спринт>.<шаг>`, например `S4.2`. Удобно для названий веток и коммитов: `S4.2: монета при уборке мусора`.

**Кто:**
- 👨 **Папа:** архитектура, сложный код, Git.
- 🧒 **Старший** (11): логика, скрипты, уровни.
- 👧 **Младший** (9): рисунки, звуки, имена, тестирование.
- 👪 **Все:** делаем вместе.

Роли — только подсказка. Пусть дети пробуют всё.

**Модель Claude** (какую выбрать для помощи с шагом):

| Модель | Когда брать |
|---|---|
| **Opus 5.5** | Архитектура, связки систем, хитрая математика (камера, шейдеры, ИИ босса), отладка непонятных багов |
| **Sonnet 5.5** | Обычные фичи: новая сцена со скриптом, UI, эффекты, интеграция плагина |
| **Haiku 5.5** | Мелочи: новые данные (`.tres`), переименования, тексты, README, мелкие правки по готовому образцу |
| **—** | Без ИИ: творческая работа детей (рисунки, звуки, голоса, придумывание, раскладка уровней, плейтест) |

> Правило для детей: ИИ объясняет и помогает, но простые скрипты дети пишут сами. Если ИИ написал код, попросите его объяснить каждую строчку.

**Готово, когда:** как проверить, что шаг закончен. Проверяем запуском игры (F5).
